## 🛠️ Technology Stack

- **Frontend Shell:** React 19, TypeScript, Vite 6, Tailwind-free Vanilla CSS tokens.
- **Design Tokens:** Pantone Cloud Dancer (`#F0EEE9`), Mocha Mousse (`#A47864`), Hairline Slate (`#CBD5E1`).
- **Takeoff Canvas:** HTML5 Canvas + SVG + OffscreenCanvas (60fps pan/zoom up to 800%).
- **3D Projection:** Custom SVG 3D Isometric Engine rendering floor slabs, extruded walls, and plenum duct prisms at $Z = 3.2\text{m}$.
- **Document Processing:** PyMuPDF (fitz), PDFium, Tesseract OCR.
- **Vector Intelligence:** ChromaDB / pgvector semantic embeddings.
- **Security & Integrity:** AES-256 GCM Company Vault, Bates stamping, FIPS 180-4 SHA-256 cryptographic package sealing.
